Getting Started

  • Drop or click Source JSON to load the reference file.
  • Drop or click Target JSON to load the file you are translating into.
  • The editor opens automatically once both files are loaded.
  • Click Reset to start a new session. You will be prompted if there are unsaved changes.

Editor

  • Source text is on the left (read-only by default). Type your translation in the right column.
  • 🔒 / 🔓 unlocks a source field if you need to correct the reference text.
  • 📋 copies the source value into the target field. Appears when the two values differ.
  • ↶ undoes the last copy and restores the previous target value.
  • 👁️ dismisses an exact-match or length warning for that item without changing the value.
  • A character and word count is shown below each field as you type.
  • A length warning is shown when the target exceeds 1.5× the source character count — a common guideline for UI strings. Use 👁️ to dismiss if the longer translation is intentional.
  • Placeholders like {{name}}, %s, {key}, and %1$s are highlighted in the source. Missing or extra ones in the target are flagged so interpolation does not break at runtime.
  • Special characters (< > " & `) trigger a warning because they can break HTML rendering or JSON parsing depending on how the app consumes the strings.
  • An orange border marks fields whose current value differs from what was loaded at the start of the session, making it easy to see what you have changed.
  • Right-to-left text direction (Arabic, Hebrew, Persian, etc.) is detected automatically per field based on Unicode character ranges and applied without any manual setup.
  • Nested keys are shown as dot-separated paths. Array items use [0], [1] index notation. The original structure and key order are preserved when you save.

Item Status Colours

  • Missing Key exists in source but is absent from the target file entirely.
  • Empty Key exists in target but its value is an empty string.
  • Extra Key is present in target but has no corresponding source key — may be obsolete.
  • Type mismatch Same key but the value type differs (e.g. string vs. array).
  • Exact match Target value is identical to the source, which usually means it has not been translated yet.

Filter Bar

  • Type to filter by key path, source text, or target text.
  • Use a regex by wrapping it in slashes: /pattern/flags (e.g. /^auth\./i to show only auth-related keys).
  • Status buttons narrow the list: Missing and Empty are the most useful when working through outstanding items. Changed shows only items whose target differs from the originally loaded value — useful for reviewing your edits before saving.

Progress Bar

Shows how many items are translated out of total. An item counts as done when the target is non-empty and differs from the source.

Floating Buttons (bottom right)

  • 💾 green saves the source JSON as a download.
  • 💾 blue saves the target JSON as a download. Will not save if any translations are still missing.
  • ↑ / ↓ scroll to top or bottom of the list.
  • 📊 exports a CSV with key, source, target, and max-characters columns. The max-characters value is ceil(source length × 1.5) — the same threshold as the in-editor length warning — so you can pass character limits directly to designers or developers.
  • 🌓 toggles dark and light theme. Your preference is saved across sessions.

Missing Translations Toolbar

Appears when there are empty or missing keys. Export just those segments as a JSON snippet to send to a translator, then import the completed file back. Useful for handing off partial work without sharing the full target file.

Session History

Logs every load, edit, save, import, and export during the session. Collapsed by default.

Keyboard Shortcuts

  • Ctrl+S saves the target file.
  • Ctrl+Enter moves focus to the next translation field.
  • F8 jumps to the next empty or untranslated item, based on the active filter.
